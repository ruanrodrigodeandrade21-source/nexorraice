# Nexo Automação

Site institucional da Nexo Automação, desenvolvido com HTML semântico, CSS e JavaScript puro. O Vite é usado somente como servidor local e ferramenta de build.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

As páginas ficam disponíveis em `/`, `/solucoes`, `/metodo`, `/planos` e `/contato`. O formulário de contato gera um arquivo de resumo localmente; ele não envia dados para um servidor.
